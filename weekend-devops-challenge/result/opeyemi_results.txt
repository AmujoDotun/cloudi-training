- SCENARIO TWO

issue- There was no permission given to anyone for the secure_data Folder.
Current Permission was 000 which was owner, group and other had no permission ------------, i got to know this through the command ls -l, which shows permissions.

Effect - I was unable to add the q1_report.csv and q2_report.csv inside that folder.

Solution- I gave the Read(list), write and Execute permission to just the owner since that was who needed it by using the command 
chmod 700 secure_data

Effect-with this i had permission to see the list of files i had created and also to create more if i wanted to.
